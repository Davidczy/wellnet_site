# WELLNET 靜態網站

此目錄包含 WELLNET TECHNOLOGY LIMITED 的靜態企業網站。

## 檔案

- `index.html`：網站頁面
- `styles.css`：網站樣式
- `script.js`：流動導覽及靜態表單提示
- `assets/wellnet-logo.svg`：本地 SVG logo
- `assets/network-hero.svg`：本地首頁視覺素材
- `*.pdf`：WELLNET 公司文件

## 本地預覽

直接開啟 `WELLNET/index.html` 即可。

## 修改資料

公司地址目前為：

```text
九龍灣宏開道15號九龍灣工業中心地下5號B舖
```

如需修改服務內容、聯絡電話或電郵，可直接編輯 `index.html` 對應區塊。

## 部署

如部署到 Vercel，可將專案根目錄設為 `WELLNET`，或把 `WELLNET` 目錄作為靜態網站內容上傳。
